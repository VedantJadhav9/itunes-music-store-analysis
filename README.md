# iTunes-Music-Store-Analysis

An end-to-end SQL and Power BI/Tableau analytics project focused on customer behavior, music sales trends, artist popularity, and country-wise purchase insights from the Apple iTunes music store dataset.

---

## Project Overview

This project analyzes transactional music store data to uncover:
- Customer purchasing behavior
- Revenue trends
- Popular artists and songs
- Genre preferences by country
- Sales distribution across regions
- Music pricing insights

The project combines SQL for data analysis and Power BI/Tableau for interactive dashboard visualization.
